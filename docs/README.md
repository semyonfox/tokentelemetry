# Documentation

Start with the [project README](../README.md) for installation and a short
description of the local CLI. The [CLI reference](../engine/README.md) covers
everyday reports, filters, cache behavior, pricing and provider setup.

The [provider inventory](provider-inventory.md) lists the 42 audited adapters,
their identifiers and their source limits. `tt agents` shows the catalog on a
machine, while `tt agents --installed` limits it to detected source paths.

The `provider-evidence-*.md` notes record the storage contracts and accounting
limits behind each reader. [Provider validation](provider-validation.md) records
the synthetic-fixture checks that support those claims.

[The port plan](provider-port-plan.md) is historical planning material. It keeps
deferred work, including terminal graph options, separate from current coverage.

[Development notes](development.md) map the Go packages for contributors.
