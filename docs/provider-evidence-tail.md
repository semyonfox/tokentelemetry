# Provider evidence: final reader batch

Primary-source snapshots used for these readers (reviewed 2026-09-19):

- **Codebuff** — official source `921b8dfb464d70e19cc035befb643702dbac931a`. The CLI writes completed messages and their native `credits` to `chat-messages.json` (`cli/src/types/chat.ts`, `cli/src/hooks/helpers/send-message.ts`, `cli/src/utils/run-state-storage.ts`). Its token utility explicitly defines `inputTokens` as gross prompt tokens containing cached input (`common/src/util/tokens.ts`). Reader behavior: preserve credits as credits, subtract cached input once for token buckets, and ignore cumulative nested `runState.messageHistory` as an accounting source. Sources: https://github.com/CodebuffAI/codebuff/blob/921b8dfb464d70e19cc035befb643702dbac931a/cli/src/types/chat.ts and https://github.com/CodebuffAI/codebuff/blob/921b8dfb464d70e19cc035befb643702dbac931a/common/src/util/tokens.ts
- **Devin CLI** — Cognition's public repository is release packaging only at `bd4163ed29e934b898f185752182c91aacac20f7`; the binary implementation is proprietary. Transcript accounting follows the primary ATIF v1.7 contract: `prompt_tokens` is gross and `cached_tokens` is its cache-hit subset. Local transcript and `sessions.db` discovery shapes use CodeBurn only as a schema fallback and therefore remain compatibility code, not a provider-owned guarantee. No default model or ACU-to-USD conversion is applied. Sources: https://github.com/CognitionAI/devin-cli/tree/bd4163ed29e934b898f185752182c91aacac20f7 and https://github.com/harbor-framework/harbor/blob/main/rfcs/0001-trajectory-format.md
- **Open Design** — official source `f5707c8cae7b61014c5e91e114b9aa07826df725` writes one `<run>/events.jsonl` and preserves cache field families. `cache_read_input_tokens` is Anthropic additive; `cached_read_tokens` is OpenAI inclusive (`apps/daemon/src/agent-protocol/acp/rpc.ts`). Reader behavior tracks start/status model changes and applies the matching family semantics per usage event. Sources: https://github.com/nexu-io/open-design/blob/f5707c8cae7b61014c5e91e114b9aa07826df725/apps/daemon/src/runtimes/runs.ts and https://github.com/nexu-io/open-design/blob/f5707c8cae7b61014c5e91e114b9aa07826df725/apps/daemon/src/agent-protocol/acp/rpc.ts
- **LingTai TUI** — official TUI `8aaf49c76ede80e77872b0805da18a653bf4e055` and kernel `13252a24b89300d52da5784ba39bf01b80e8d4d6`. The kernel declares `logs/token_ledger.jsonl` the append-only source of truth and documents daemon calls mirrored into the parent ledger. The TUI defines ledger `input` as gross, with `cached` as a subset. Reader behavior scans only immediate agent ledgers, includes parent mirror rows, and never descends into daemon ledgers. Sources: https://github.com/Lingtai-AI/lingtai-kernel/blob/13252a24b89300d52da5784ba39bf01b80e8d4d6/src/lingtai/kernel/token_ledger.py and https://github.com/Lingtai-AI/lingtai/blob/8aaf49c76ede80e77872b0805da18a653bf4e055/tui/internal/fs/session.go

Known limits: Devin's local directory/database schema has no provider-owned public contract; Open Design location discovery follows its current application layout but has no stable override environment variable; Codebuff token fields are uncommon in top-level UI messages, so most records are credit-only; LingTai rows written before per-call model attribution remain explicitly unpriced.
